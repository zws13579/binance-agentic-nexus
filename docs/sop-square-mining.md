# 币安广场「内容挖矿 (Write to Earn)」SOP

> 迁移自原 AGENTS.md §四-3，供 Agent 按需读取。

## 第一步：全网权威财经热点与聪明钱选品

**真实数据驱动，彻底移除失效网页爬虫。**

- **宏观与行业热点**：直接从传统顶级金融媒体（CNBC、Yahoo Finance、MarketWatch）即时头条动态提炼宏观财经议题（如美联储利率决议、通胀预期、ETF 进展）。
- **资产选品联动**：结合 Web3 `smart-money-inflow`（聪明钱大幅净流入榜）与 `social-hype`（Web3 链上代币热度榜）锁定机构与聪明钱资金异动标的。
- **严禁虚假标签与死数据**：彻底移除失效的网页端 `square/trends` 爬虫（该页面受 AWS WAF 防护拦截）以及任何伪造标签，文末标签必须为真实宏观事件或行业主题（如 `#美联储加息 #大饼76K防线争夺`）。

## 第二步：真伪查验与新闻求证

- 联动 Web Search / 顶级金融媒体检索过去 24 小时真实宏观/行业事件（美联储利率决议、国会法案进展、ETF 审批、链上储备证明）。
- **严禁胡编乱造**。

## 第三步：真人交易员拟真文案

### 文案绝对禁忌

- **严禁使用任何 Markdown 格式**（禁止 `**加粗**`、禁止 `# 标题`、禁止 `- 列表`、禁止成排 Emoji）。广场显示 Markdown 会造成严重排版乱码。

### 正确格式

- 采用自然段落换行
- 包含大写 CASHTAG（且 Cashtags 数量严格 ≤ 3，如 `$BTC`、`$ETH`）
- 挂载真实关联热搜话题（如 `#美联储加息25bp #大饼76K防线争夺`）

### 交易员风格

- 严禁自称"老韭菜"
- 严禁使用"总而言之/综上所述"
- 拒绝中庸和稀泥
- 用冷峻且掷地有声的断言收尾

## 第四步：API 自动化推流发布

- 读取 `.env` 中的 `BINANCE_SQUARE_OPENAPI_KEY`
- 使用 `publish_square.mjs` 或 `pipeline.mjs --publish-text / --file` 直接推流发布
- 发布前可用 `--dry-run` 模式预览内容
