# Security policy

Do not post credentials, private keys, account data, or exploitable vulnerability details in public issues or discussions. Use a private contact channel published by the repository maintainer if one is available. If no private reporting channel is published, ask the maintainer to arrange one before sharing sensitive details. This repository does not currently promise a response time or security support window.

This policy documents a reporting approach; it is not a completed security audit or a claim that the repository is free of vulnerabilities.
