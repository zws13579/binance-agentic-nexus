# Security policy

Do not post credentials, private keys, account data, or exploitable vulnerability details in public issues or discussions. Use GitHub's built-in private vulnerability reporting only if the repository page explicitly offers a "Report a vulnerability" option. If that option is unavailable, no private reporting channel is published here; do not send sensitive details through a public issue or discussion. Wait until a private reporting channel is arranged before sharing them.

This policy documents a reporting approach; it is not a completed security audit or a claim that the repository is free of vulnerabilities.
