## 一、 广场推荐算法“两大万能公式”

平台官方算法对高完读率、高互动、高权重推荐内容定义了极简万能公式：

### 1. 交易与行情类内容万能公式
$$\text{看涨跌} + \text{决策逻辑 (30秒懂)} + \text{行动预案 / 真实凭据}$$
- **30 秒定律**：让读者在 30 秒内迅速理解你的交易决策（为什么看涨/看跌、为什么在此点位进出场）。把“决策推导过程”写透，读者才愿意停留、点赞和跟单。
- **拒绝无效噪音**：不写无逻辑的盲猜或空洞喊单，依靠盘面结构、深度流动性与衍生品指标给出扎实论据。

### 2. 热门话题与宏观新闻类万能公式
$$\text{权威事件} + \text{核心冲击 (3秒Hook)} + \text{个人独家观点} + \text{动作预案 (我打算怎么做)}$$
- **必答三问**：官方明确要求，新闻与话题切入时必须回答三件事：
  1. 你对这个事件怎么看？
  2. 会对相关资产/标的产生什么链式反应？
  3. **你打算怎么操作/应对？**（明确给出交易员行动指引）。

## 二、 去 AI 味与高留存创作铁律

### 1. 开头“3 秒抓人定律” (The 3-Second Hook)
- **拒绝平铺直叙的新闻通稿**：开头 3 秒抓不住眼球，算法监测到跳出率过高就会立即中断推荐池推流。
- **第一句话直接亮剑**：首句直接抛出**最具反常识冲突、冷酷真相或一针见血的核心结论**（例如：“某某币看似放量暴涨，实则是空头流动性踩踏的绝后逼空”、“华尔街对加密市场的态度正在变得极端残忍”）。

### 2. 真实交易员客观视角（严禁自称“老韭菜”）
- 语气冷静、客观、就事论事，凭借资金费率、做市商洗盘、筹码分布说话。
- **绝对禁止自称“老韭菜聊聊大白话”、“老韭菜说句心里话”、“作为老手”等廉价自封标签**。此类称谓油腻且刻意，极易被读者识别为杀猪盘或水军，严重削弱专业公信力。
- 绝不使用“总而言之”、“综上所述”、“值得注意的是”等机械过渡词。
- 绝不使用“教科书级”、“多空双杀”、“重磅利好”、“飞灰湮灭”等劣质 AI 翻译腔。

### 3. 零 Markdown 八股文（不可妥协原则）
币安广场移动端/Web 端对 Markdown 渲染支持有限，符号暴露会导致严重排版灾难：
- **严禁**出现任何 `**` 加粗语法；
- **严禁**出现 `#`、`##`、`###` 等 Markdown 标题语法（仅文末允许使用 `#标签`）；
- **严禁**出现 `-`、`*`、`1.`、`2.` 等死板列表符号；
- **严禁**出现成排的装饰性 Emoji 列表（🚨、📊、⚠️、💡、🔥）；
- **正确排版**：所有段落通过自然空行（回车换行）分隔，长短句交替错落，营造真人随笔节奏。

### 4. 交易员动作闭环（给出明确应对预案）
- 正文收尾前，必须明确给出具体的交易员预案：
  - “挂单支撑位设在 XXX”
  - “跌破某点位果断止损”
  - “当前缩量阶段只观望、绝不现货追高”
- 让内容不仅有认知冲击，更能提供具备实操参考价值的决策动作。

### 5. 自然涨粉导流语 (Natural Follow Hook)
- 官方清单明确认可：*“内容结尾可以自然地提一句：关注我，会分享更多交易内容/实盘推演，慢慢就能累积粉丝。求关注可以，刷关注不行。”*
- **规范要求**：在正文末尾用极其克制、专业的一句话自然带过（例如：“关注我，持续拆解主力盘口与实盘应对策略。”），严禁低俗求互关、严禁红包诱导。

## 三、 官方算法明确的“五大限流红线” (Shadowban Redlines)

凡触犯以下红线，将被广场推荐系统直接降权或移出公域推荐池：

1. **虚假新闻（一票否决）**：
   - 官方明确警告：**“AI事实验证失败会导致您直接没流量”**。
   - 所有宏观事件与数据必须依托 CNBC、Yahoo Finance、MarketWatch、The Block、CoinDesk 或币安官方公告交叉核验，坚决杜绝广场三手传闻。
2. **硬蹭流量与标签滥用**：
   - 滥打无关热门币对标签会严重破坏账号长期健康度。
   - **Cashtag 硬指标**：`$BTC` 币种标签数量**严格 $\le 3$ 个**（超过 3 个将触发 OpenAPI 报错），且必须与文中核心标的高度一致。
   - **Hashtag 真实性**：文末附带 1~2 个真实宏观/行业话题（如 `#美联储加息 #合约多空博弈`）。
3. **纯快讯复读与无脑搬运**：
   - 官方指出：*“抄袭、重复内容、快讯类等重复内容，加上你自己的个人观点，才能保平安。”* 纯快讯不给推荐。
4. **过量 Emoji 堆叠与故事会骗点击**：
   - 避免故事会、虚假截图、擦边图以及大面积表情符号骗点击行为。
5. **机器刷量与红包黑产**：
   - 严禁机器人刷评、严禁通过红包帖子反复编辑诱导无意义互动。

## 四、 内容形态与自适应主题切入

1. **形态推荐**：
   - 首选**短动态（`contentType: 1`，字数控制在 250~400 字）**：手机一屏直接完整展现，完读率最高，最契合算法传播。
2. **多模态自适应主题模型（消除文本指纹同质化）**：
   - **宏观联动型 (Macro)**：以美联储利率预期、通胀数据、全球主权流动性为锚，拆解大饼资金流向；
   - **衍生品猎杀型 (Derivatives)**：以资金费率倒挂、多空持仓比极端偏离、主动买卖量为锚，揭示轧空/杀多陷阱；
   - **筹码洗盘型 (Whale / Liquidity)**：以交易所大额存取、巨鲸转移、挂单墙与支撑真空为锚；
   - **事件催化型 (Catalyst)**：以监管法案推进、ETF 调仓、协议规则调整为锚。

每篇内容依据即时盘面动态切换切入点，坚决不使用死板模板。
